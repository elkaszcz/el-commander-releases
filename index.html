Blazing fast.
Snappy to the bone.

A single native binary: no runtime, no interpreter, no warm-up. cm is on screen before your finger leaves Enter, and every keypress after that lands instantly.

  • Never blocks the UI. Copy, move, delete and directory sizes run on background threads with live progress, and you can cancel any of them mid-flight.
  • Redraws only on change. An idle-redraw flag skips frame building entirely when nothing has changed.
  • Huge files, no limits. The viewer and editor stream very large files, and hex view opens binaries.
  • Slow links stay responsive. Directory reads get a bounded grace window, so an SFTP hiccup never freezes the screen.

Paranoid by design.

// safety guarantees. Every box is ticked.

Safety check

No cp, rm or mv is ever spawned. Every file operation is native Rust on top of capability-based cap-std, so there is no shell to inject into and every error is handled by the app.

  • [x]direct syscallsno shell, no injection
  • [x]atomic writestempfile → fsync → rename
  • [x]zip-slip & tar-sliptraversal entries rejected
  • [x]SSH host keyschanged key = MITM refused
  • [x]secret hygieneZeroizing, wiped on drop
  • [x]preview helperSHA-256 verified before exec
  • [x]URL handlerhttp · https · mailto only
  • [x]signed releasesMinisign-verified on install & update
